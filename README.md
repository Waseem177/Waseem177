### 📌 Featured Projects

**[forgotten-in-msa](https://github.com/Waseem177/forgotten-in-msa)** — Cross-lingual unlearning audit
Unlearn a fact in English, check whether it survives in Arabic. The standard audit says it does; adding a base-model control shows the model never learned those facts in Arabic at all, so the apparent 26% effect falls to 2.5%. QLoRA, GradDiff, TOFU, Qwen2.5-0.5B on one 8 GB GPU.

**[pqc-federated-learning](https://github.com/Waseem177/pqc-federated-learning)** — Post-quantum federated learning
Five simulated hospitals training a shared model, secured with NIST's ML-KEM and ML-DSA, with differential privacy and Byzantine-robust aggregation.

**[network-intrusion-detection](https://github.com/Waseem177/network-intrusion-detection)** — Explainable IDS
LSTM on CICIDS2017 reaching 99.75% on DDoS. SHAP showed it was mostly counting ACK flags — excellent on DDoS, blind to brute force and web attacks.
